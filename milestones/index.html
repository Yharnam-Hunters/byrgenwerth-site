Milestones

The project's milestones in pictures: how far the game gets on Paleblood's own runtime, from the first recorded boot to the latest. First, the frames Paleblood's own renderer has drawn, in the order they first appeared; then the boot journey, generated from the saved boot records by tools/sync_progress.py.

Visual history: frames from Paleblood's renderer

These are the game's own frames, drawn on a PC by Paleblood's runtime and renderer from the maintainer's own copy, at full resolution as rendered (1920x1080; one render-target view at 896x832), oldest first. Frames marked debug view show one of the renderer's internal targets, not what the game puts on screen. Select a frame to see it at full size with its full caption (arrow keys move between frames, Esc closes). Each passed the media review on its own. Nothing here comes from another project, and no extracted game assets appear on this page. Bloodborne and its logos and art are © Sony Interactive Entertainment / FromSoftware; they are shown as evidence of technical milestones. Times are UTC: when the pull request that made each frame possible merged or, for local runs, when the frame was captured.

Before 6 November 2026: black. The game ran its frames and flipped them (#310), and the display showed them (#313), but nothing drew into them. From #369 (6 November, 07:20) the renderer was wired into the running game, waiting for the game's drawing calls to reach it.

After the title: local runs. Frames marked local run come from the maintainer's own runs of main with scripted input and with pull requests that were still in review applied; each caption names them. They are not saved boot records.

Later milestones (the first playable scene) are added here as they are reached.

The boot journey

Each point is one recorded boot of merged main, and its height is the furthest milestone that boot reached. A boot is recorded with tools/boot.py after runtime changes merge. Merging code does not move a point by itself; only a new genuine boot does.

What the screen shows

Reaching first flip means the game finished a frame and asked the screen to show it. Paleblood can show the frames, in a window or as captured images (#313), and since 6 November 2026 its own renderer draws them: in the maintainer's local runs with the display on, the boot shows the studio logos and reaches the title screen (#441, #442), and with scripted input (#447) and pull requests that were then still in review it gets past the title to the main menu and the first settings screens, the opening cinematic and character creation (above). The saved boot records above run with the display off and no input, so they do not show this. The renderer's phases are on the Runtime page.
