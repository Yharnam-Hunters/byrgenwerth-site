Milestones

The project's milestones in pictures: how far the game gets on Paleblood's own runtime, from the first recorded boot to the latest. Everything on this page is generated from the saved boot records by tools/sync_progress.py; nothing is drawn by hand.

The boot journey

Each point is one recorded boot of merged main, and its height is the furthest milestone that boot reached. A boot is recorded with tools/boot.py after runtime changes merge. Merging code does not move a point by itself; only a new genuine boot does.

The game is in memory: its program and libraries are loaded and linked.

What the screen shows

Reaching first flip means the game finished a frame and asked the screen to show it. The frame is still black. Paleblood can show the frames now, in a window or as captured images (#313), but until the renderer is built the game's drawing work goes through a temporary stand-in that completes it without drawing. The renderer's four phases are on the Runtime page.

When the renderer draws its first pictures, frames from those runs will appear here. Each image is reviewed on its own before it is published, as the media review requires: its source, what it shows, how much of it is needed, and the maintainer's approval. Nothing from another project, and no extracted game assets, appear on this page.
