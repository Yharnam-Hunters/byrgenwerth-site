Target

The exact game build Paleblood works on, and how its executables were prepared.

Title
CUSA03173, EU
Version
1.09, the update merged over the base game
Executables
Converted from SELF to ELF with SelfUtil-Patched. The SELFs were fake-signed with no encrypted segments, so conversion only unwraps them. The converted ELF has no section headers; see Ghidra & PS4 Quirks.
Addresses
PS4 virtual addresses, Ghidra image base 0x400000 (the ELF p_vaddr plus 0x400000), the same as the community patches. See Ghidra & PS4 Quirks.
