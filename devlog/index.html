Devlog

How Paleblood moves, week by week: what merged, what is proposed, and what is still blocked.

One post per week (one per day before 19 October 2026), updated as pull requests and milestones land, in six standard sections. Written in plain English: if a term is new, check the Glossary first.

  1. 2026-10-26

    Week of 26 October 2026: 40 merged pull requests

    Pull requests by @EzequielRindello, @ThisIsAkill, @evill33t. No new function was verified this week. 23 more are open and in review. The maintainer reviews this draft before it is published.

    Read the post
  2. 2026-10-19

    Week of 19 October 2026: A bounded verification pipeline and a clearer site

    The documentation caught up with merged tracing, control-flow feedback and the opt-in automation prototype, the runtime numbers followed the newest merged boot record, and the site got a new menu. None of it establishes a new verified function or startup milestone.

    Read the post
  3. 2026-10-11

    11 October 2026: more imports supplied, same boot blocker

    Two genuine boot traces raised the supplied system imports from 238 to 247 of 686, but startup still stops at the same call, scePthreadAttrGetaffinity. The day also re-checked the millisecond clock against the original code, documented IPv4 text conversion, and published the roomier sidebar menu.

    Read the post
  4. 2026-10-10

    10 October 2026: recorded verification and runtime foundations

    This day improved capture reliability, verified one function from existing recorded calls, and added four deterministic network byte-order imports. The tooling work did not itself advance game execution.

    Read the post
  5. 2026-10-09

    9 October 2026: a path for runtime contributors

    Runtime-only contributors can implement a documented syscall without access to a game dump or recorded captures. This day's work prepared the issue #34 contribution route and clarified what the current boot evidence does and does not establish.

    Read the post
  6. 2026-10-07

    7 October 2026: a new direction, our own runtime

    Paleblood opened its code to contributors and began building a clean-room runtime of its own. This entry combines the day's runtime work and decompilation progress.

    Read the post
  7. 2026-10-06

    6 October 2026: from an empty repository to the frame loop

    The first day: the target was prepared, the repositories and tooling were set up, and the first Ghidra export and verified frame-loop replacements were completed, from the clock up to the function that runs every frame.

    Read the post
