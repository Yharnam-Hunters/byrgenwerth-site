2026-11-09

Week of 9 November 2026: past the title to the first 3D scene

In local runs with scripted input the game now gets past its title: save data, the main menu, the Brightness and Controls screens, and the opening cinematic, the first 3D scene Paleblood's renderer has drawn; the logos and title run at 30 fps. A batch of runtime calls merged, with work by @EzequielRindello, @BluePinetree, @evill33t and a lead from @sweetbbak; no new function was verified. This post grows through the week.

Runtime and boot progress

So far this week: past the title, to the first 3D scene (local runs). Advances game execution in the maintainer's local runs; the saved boot record has not been re-recorded since #443.

  • With scripted input, the maintainer's local runs take "Play Offline", create the save data, show the main menu and, after New Game, the first-run Brightness and Controls screens; scripted on, the game's opening cinematic draws, the first 3D scene Paleblood's renderer has drawn. Frames: Milestones.
  • Contributors: @EzequielRindello's sceKernelWrite and sceKernelPwrite (#444), the save code's first writes after "Creating save data", and _exit (#454); @BluePinetree's check of a module hook's first bytes before patching, so another libc.elf build is refused by name (#456).
  • A batch of runtime calls merged on 10 November, each with its own tests: renaming, truncating and folders #458; deleting a save and the disc map #459; thread join, detach, explicit scheduling and once #460; timed mutex and reader-writer locks #464; unmapping, protecting and typing memory #467; signal masks and thread names #469; time zones, RFC 2822 dates and the network tick, and no system events #466; the C library's calendar and formatted output for the file library #468; the pad's motion settings and an unplugged mouse #462; offline PSN authorization and the IP address query #461; IPv4 address to text #465.
  • Audio output with no block: the movie player's sound thread can pass none when it has nothing to give, which stopped a slower run during the opening movie; the call now waits for room and hands nothing over (#481).

Renderer: what the menus and the first 3D scene need. Advances game execution in local runs.

  • 8- and 16-bit buffer formats, and stops that name the shader (#457): with them the main menu draws.
  • Depth and stencil tests that read the buffer, stencil steps and a depth target larger than the colour target (#471): choosing New Game needed all three; the boot then reaches the Brightness screen.
  • Image descriptors loaded behind a branch (#474), two-channel 8-bit images (#476) and samplers with anisotropy fields but plain filters (#477): the next scene after Controls, the opening cinematic, draws.
  • Speed: one GPU batch per submitted command buffer (#463, no measurable change by itself), then the render targets' tiling copies moved to the GPU (#472): the logos and title run at the game's 30 fps cap in local runs, up from about 14, with the JAPAN Studio frame still pixel-identical.
