2026-11-02

Week of 2 November 2026: first flip, no call stops the boot, and the title screen

The boot reached first flip on merged main, then ran with no system call stopping it; Paleblood's own renderer drew the studio logos and the title screen, and local runs with scripted input reached the main menu. Contributions by @evill33t, @EzequielRindello, @BluePinetree and @gabee12; no new function was verified.

Runtime and boot progress

The week in brief: from the October stop to the title screen. Advances game execution.

  • 3–4 November: @BluePinetree's #207 removed the boot's October stop (scePthreadAttrGetaffinity inside the bundled C library). Recorded boots of merged main then climbed from milestone audio (5 of 8, #295) and video out (6 of 8, #300) to first flip, 8 of 8 (#310, 4 November): the game hands its first frame to the screen.
  • 5–6 November: a round of runtime work answered every call between the first flip and the game's main loop: PlayGo #370, the user service #372, one controller at rest #373, the clock #378, #379, PSN and network offline #380, #381, #382, #385, #386, file details and errno #376, thread exit #389, #399, add-ons #392, the splash screen #396, save data #402, trophies #405, and sound: ATRAC9 decoded with LibAtrac9 and played on the host #394, #398, #406. The recorded boot after it (#408) is the first that no system call stops: it calls 243 imports and keeps running to the time limit.
  • Movies play through the console's movie player, decoded with FFmpeg #419, #420; a real gamepad and keyboard work with --input host #431; scripted input lets unattended runs press buttons on a timetable #447. Kernel details found by boots: priority-ordered semaphores #426, memory-protection ranges #422, no-overwrite maps #423; later file and network calls #448, #449, #450, #451.
  • Contributors: @EzequielRindello implemented time, sleep, nanosleep, thread keys, pthread_cond_timedwait and mutex ownership #241, #296, #298, #315, #351, #353; @evill33t landed loader and macOS groundwork and loading the decompilation's replacements in the runtime's own boot harness #214, #215, #216, #217, #218, #220, #224, #225, #226, #227, #229.
  • The boot recorded after the renderer work (#443): first flip, 243 imports called, 234 of them answered by the runtime, still running at the limit. It runs with the display off and no input.
  • Maintainer's local runs (not saved records): the title screen draws (below), and with scripted input and the then-open #444 the game takes "Play Offline", creates its save data and shows its main menu (6 November). Frames: Milestones.

The renderer: from black frames to the title screen. Advances game execution (in local runs with the display on).

  • Phase 1, the display: every frame buffer gets a window or captured image #313. Phase 2, the shader translator from AMD's GCN code to Vulkan's SPIR-V, written from AMD's manuals: the decoder and a census of the game's 175 instructions #316, straight-line compute #319, branches #330, typed buffers #332, vertex and pixel shaders #333, arithmetic #334, clip distances #343, guest addresses #346; macOS CI compiles every test shader as Metal #331.
  • Phase 3, hooking the game's own drawing layer: the GPU library's packet writers and key entry points mapped #335, #341, a record of its calls per command buffer #342, #344, #345, #401, and the draw executor that plays them on a Vulkan GPU #349, #368, #369.
  • 6 November, #411–#442: @evill33t's verified GPU-library replacements (#411, from #233) report the game's draws to the renderer #414; compute passes, tiled textures, sampling, blending, depth, fetch shaders, indexed draws and BC textures followed. Results in the maintainer's local runs: the first non-black frame (#433), the first logo (#441), then the JAPAN Studio and FROM SOFTWARE cards and the title screen once #442 made the renderer about 22 times faster (66 to about 1,445 frames in a 90-second boot).
