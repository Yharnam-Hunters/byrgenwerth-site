2026-11-16

Week of 16 November 2026: thousands of copies join function families

Contributor @FFwLo grouped thousands more copies of small engine functions into families, including families of functions that differ only in the addresses they reach, and @evill33t continued FMOD's thread code. The clinic's first encounter, reached last week, is still the furthest point in local runs, at about 11 fps.

Runtime and boot progress

So far this week: no new reach; the clinic's first encounter is still the furthest point (local runs). Does not advance game execution yet. In local runs from a save at the clinic's start with a scripted controller, the game still runs the clinic's first encounter through to the Hunter's Dream with no stop, at about 11 frames a second against the game's 30 (last week; Runtime). The saved record on merged main (#1082) is unchanged: first flip, 686 of 686 imports bound. The work this week is the clinic's speed and the rare compute stop early in the clinic walk; nothing of it has merged yet.

Decompilation and verified functions

So far this week: families of functions that differ only in their addresses. Decompilation infrastructure; the function count moves much more than the bytes.

  • @FFwLo's relative-shape families (#1099): copies of one function the compiler emitted for different classes, identical except for the addresses they call or read, now share one replacement that is told each copy's addresses. The first is the static wide string initializer (439 copies), and a run of pull requests on it followed: thread allocator, delegate and destructor families (#1138, 879 copies), seventeen deleting destructor shapes (#1141, 3,196 copies), a Scaleform destructor and its deleting twin (#1142), four static vtable setters (#1144, 1,131 copies), the remaining 8-byte array reallocations (#1145), fixed slot table fillers (#1147), the menu's named resource release (#1151), small member-releasing destructors (#1152), member-destroying destructors (#1156, 227 copies) and twelve small relative families (#1155). With constant field setters (#1112), float, double and signed field accessors (#1113) and string writers, toggles and resets (#1135), the number of families in the merged function table more than tripled since 15 November (Function families).
  • Byte-exact matching records for 23 families (#1165, 1,538 copies). The families added this week are replaced and edge-verified, not yet verified: the verified count is unchanged at 285 hand-written functions and 18,019 family members (Progress).
  • @evill33t initialised FMOD's thread transport fields (#1161), edge-verified.
