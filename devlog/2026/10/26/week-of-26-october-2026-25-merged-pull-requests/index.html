merged#135 runtime: script imports called inside a traced call, by @ThisIsAkill. Merged 2026-10-30.

  • Findings: an import's writes are compared only above its return slot; a stale pointer below the stack in an unused argument register otherwise recorded the import's own stack frames as writes; imports called inside a traced call are scripted in the case (return value and pointer-argument writes, in order); their argument counts are not known yet, so cases use argc 0; thread-local storage (fs/gs) reads still end a trace; that is the next gap for capture; hooked calls are recorded by tracing the original from a relocated entry; nested hooked calls follow the callee's original, and the recorded cases replay through tools/verify.py; tracing is opt-in (BB_CAPTURE_TRACE=1) because it runs microseconds per instruction; pair it with BB_CAPTURE_ONLY.
