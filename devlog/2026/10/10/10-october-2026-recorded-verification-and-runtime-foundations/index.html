2026-10-10

10 October 2026: recorded verification and runtime foundations

This day improved capture reliability, verified one function from existing recorded calls, and added four deterministic network byte-order imports. The tooling work did not itself advance game execution.

Runtime and boot progress

Paleblood PR #50, merged at 816ea964c2d5db49271ad3131cad4a24e3d0bcc5, added sceNetHtonl, sceNetHtons, sceNetNtohl, and sceNetNtohs. These implement fixed-width host/network byte-order conversions; socket, resolver, epoll, and online behavior remain uncovered. The saved boot result still stopped at scePthreadAttrGetaffinity (238/686 system imports provided), within contributor-owned issue #34. No boot run was made for this change.

Decompilation and verified functions

Paleblood PR #48 promoted frame_timing_pace_frame (0x02434770) using its existing evidence: 585/585 recorded calls and 26/26 edge cases. Its approved independent review remained in place. PR #49 refreshed generated public documentation from the merged verification result; it added no runtime behavior or new cases. The verified function count reached 21.

Tooling and automation

Paleblood PR #46 made capture output stable, recorded function/run provenance, refused unsafe paths and existing case files, and kept older schema-1 cases replayable. PR #47 added an isolated typed adapter proof with explicit signature and memory descriptors. Synthetic fixtures passed capture, serialization, replay, and verification; unsupported signatures and missing descriptors failed closed. Production replacements still do not call this adapter, so these tests produced no real game captures.

Paleblood PR #53, merged at fec0551, makes runtime issue counts recognize registered RT_SYSLIB entries without waiting for a boot run. This corrected issue #41: the four network byte-order helpers from PR #50 are now checked and the group reports 4/175 implemented. Focused parser/count tests and the 95-test Python suite passed; GCC/Clang builds and CTest passed 11/11 each. This improves progress tracking only; actual boot did not advance.

Paleblood PR #54, merged at 8abd5531f919047ee8d28bae7b16a0332f5fb764, adds a synthetic fake-host test for the existing version-1 host API consumer. It checks version rejection, image handoff, guest-relative hook registration, named/address hook skips, probe ordering, and error propagation. GCC and Clang Release builds and CTest passed 12/12 each; policy, hooks, and required CI checks passed. This improves ABI regression coverage only: the legacy host remains active, no equivalent replacement exists, and boot execution did not advance.

Documentation and website changes

The frame-timing page and generated progress data were refreshed from merged Paleblood revision 816ea964c2d5db49271ad3131cad4a24e3d0bcc5. The public site was published at 21e1d26. The runtime notes keep the production observer and capture integration explicitly unfinished. Public source documents the synthetic limits alongside the results.

The Runtime, Architecture, and CI Setup pages were audited and updated against Paleblood 8abd5531f919047ee8d28bae7b16a0332f5fb764; all 30 public wiki pages plus generated fragments, navigation, metadata, image references, and search output were reviewed. The former homepage artwork could not be restored because its creator and redistribution rights are unrecorded. Automatic synchronization remains inactive: no least-privilege App credentials exist, and the current sync path executes code from the public Paleblood checkout. A final output review also removed a Runtime-page link into the legacy scaffold README so retired integration names stay out of public routes and search content. The license and dependency findings remain in the private maintenance audit. This documentation work did not advance game execution.

Tests and validation

The capture changes passed GCC and Clang builds and all 11 CTest suites. The verification promotion used the 585 recorded calls plus 26 edge cases. The four network helpers passed registry tests with known byte patterns, zero, maximum-width values, and round trips; both compiler builds and all 11 CTest suites passed. Clean-room, policy, hook, and session audits also passed.

Blockers and next steps

No production capture integration or game execution advanced. 0x02713870 still has no matching recorded inputs and remains blocked. The earliest saved boot blocker remains the issue #34 affinity import; synthetic capture tests are not substitutes for matching recorded cases or production ABI evidence.
