2026-10-11: Development progress

Runtime and boot progress

Genuine tools/boot.py --trace execution used the local Bloodborne eboot.elf (SHA-256 ca8813862d7b1345a6791b7d88cc1d383ede2a6bbc944f39dd3c0e0e3ad9e285) with Paleblood PR #61 head 3e4886b, based on merged main 251d426. The trace resolved 246/686 imports (219 from bundled game modules, 27 implemented by Paleblood, plus two separately reported unresolved NetCtl diagnostics), reached seven import calls, and remained at loaded (0/8). It stopped at scePthreadAttrGetaffinity in libkernel from libc.elf, returning to libc.elf+0x81ad5, the same blocker as the previous 238/686 baseline. The additional eight imports reflect merged PRs #50 and #59 plus corrected unresolved classification; startup did not advance. Issue #34 remains contributor-owned. No new decompilation verification was performed.

Genuine tools/boot.py run on merged Paleblood main 68d5f93d7938be6b72eb8d5d7e32ef8585e51094 used the local Bloodborne 1.09 executable (SHA-256 ca8813862d7b1345a6791b7d88cc1d383ede2a6bbc944f39dd3c0e0e3ad9e285) and its required bundled modules. The run resolved 247/686 imports (219 bundled, 28 runtime), reported two separately registered unresolved diagnostics and 437 unbound imports, and reached seven import calls. It remained at loaded (0/8), stopping at scePthreadAttrGetaffinity in libc.elf, returning to libc.elf+0x81ad5. Compared with the saved 246/686 trace, one more import is supplied by PR #63; startup did not advance. This is actual game executable boot-harness execution, not a full gameplay run.

Decompilation and verified functions

The generated catalog remains at 21 verified, 30 replaced, and 30 edge-verified functions. No new original-code differential or verification promotion was performed; this session did not repeat the existing frame_timing_get_monotonic_ms comparison.

Tooling and automation

Against Paleblood source b9fb62df910652315eab6dbebe6a81362548c76d, the existing differential harness executed the original x86-64 instructions at frame_timing_get_monotonic_ms (0x0111a7f0) from the local Bloodborne executable beside Paleblood's replacement. All 1,767 recorded inputs and 10 edge inputs matched, with zero differences. This repeats the evidence for an already-verified function: verified/replaced counts did not change. Original instructions ran in the isolated verifier; the game boot sequence did not advance. No executable or capture data was added to the repository.

Documentation and website changes

The roomier submenu from private PR #27 (merge 2f8709c) is live at public site commit e691994; its GitHub Pages deployment succeeded. Submenus are indented along a guide line with more room between entries, and one section opens at a time. Core routes, the image and the search index returned HTTP 200; publication privacy scanning found 105 generated files clean. At the maintainer's request the sidebar now shows the menu artwork alone: its caption was removed, and the r_dsgnd/SteamGridDB credit and ©2014 Sony notice moved to the Credits page. Documentation and navigation only; game execution did not advance.

The merged-source network group remains 8/175 implemented; the latest saved genuine boot record provides 246/686 imports (219 bundled, 27 runtime), reaches seven imported calls, and remains at loaded (0/8), blocked at contributor-owned scePthreadAttrGetaffinity. This is a coverage/reporting correction, not game-startup progress. No duplicate daily post was created; no publication was performed.

Updated the Runtime and Runtime system-call pages against merged Paleblood source 68d5f93d7938be6b72eb8d5d7e32ef8585e51094. Tests and validation
