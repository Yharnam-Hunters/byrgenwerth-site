2026-10-11

11 October 2026: more imports supplied, same boot blocker

Two genuine boot traces raised the supplied system imports from 238 to 247 of 686, but startup still stops at the same call, scePthreadAttrGetaffinity. The day also re-checked the millisecond clock against the original code, documented IPv4 text conversion, and published the roomier sidebar menu.

Runtime and boot progress

A traced boot run (tools/boot.py --trace) on the local Bloodborne executable, using Paleblood PR #61 on top of merged main 251d426, resolved 246/686 imports: 219 from bundled game modules and 27 implemented by Paleblood. It reached seven import calls and stayed at loaded (0/8), stopping at scePthreadAttrGetaffinity, the same blocker as the earlier 238/686 baseline. The eight extra imports come from merged PRs #50 and #59 and a corrected count of unresolved imports; startup did not advance.

A second boot run on merged Paleblood main 68d5f93 resolved 247/686 imports (219 bundled, 28 runtime): PR #63 supplies one more. It still reached seven import calls and stopped at scePthreadAttrGetaffinity (0/8). This was the real game executable in the boot harness, not a gameplay run.

Decompilation and verified functions

The catalog is unchanged at 21 verified, 30 replaced, and 30 edge-verified functions. No function was promoted today.

Tooling and automation

The differential harness ran the original instructions of the millisecond clock (0x0111a7f0) beside Paleblood's replacement: all 1,767 recorded inputs and 10 edge cases matched. This repeats the evidence for an already-verified function, so the counts did not change. No executable or capture data was added to the repository.

Documentation and website changes

The roomier sidebar menu is live at public site commit e691994. Submenus sit along a guide line with more space between entries, and one section opens at a time. The sidebar now shows the menu artwork alone; its credit and copyright notice moved to the Credits page.

With PR #61 merged, the Runtime pages now note that sceNetCtlGetInfo and sceNetCtlGetNatInfo are callable but deliberately fail loudly, so they no longer count as implemented. This corrects the coverage numbers; it is not startup progress.

The Runtime pages also explain the new sceNetInetPton support (IPv4 text conversion only), what evidence backs it, and the limits of its synthetic tests. The network group in issue #41 now stands at 9/175 implemented imports.

Tests and validation

Fresh GCC and Clang builds passed, with 13/13 CTest cases each. The session audit, hook tests, game-data policy, progress consistency, and function validation checks all passed.

Blockers and next steps

scePthreadAttrGetaffinity is still the first unresolved call and the earliest boot blocker; it is tracked in contributor-owned issue #34. Once it lands, the next boot run will show how far startup gets past the loaded stage.
