Week of 19 October 2026: A bounded verification pipeline and a clearer site

The documentation caught up with merged tracing, control-flow feedback and the opt-in automation prototype, the runtime numbers followed the newest merged boot record, and the site got a new menu. None of it establishes a new verified function or startup milestone.

Runtime and boot progress

Catching up on 11–15 October. @clee's merged PR #66 makes getpagesize stop by name under both import names instead of guessing. The game's own executables bound the answer to a divisor of 16384 (4096, 8192 or 16384), and no public source says which one the PS4 reports, so only a console observation can settle it. The entries do not count as implemented.

@EzequielRindello's merged PR #62 compares guest thread handles, and PR #72 supplies the documented sched_yield path. scePthreadYield stays unresolved because its PS4 return signature is unknown. The registry tests are synthetic. No boot was run for this audit; the saved result still stops at scePthreadAttrGetaffinity, before the first startup milestone.

  • System calls: memcpy; memset.
  • Tests: 2 synthetic runtime test(s); the effect on the real boot is measured after merge, so this is not a boot result.
  • Left unresolved: PS4 C library behavior for undefined cases (overlapping memcpy regions, null pointers) is not modelled.

Decompilation and verified functions

Catching up on 11–15 October, which fell between the daily posts and the first weekly one. @ThisIsAkill's merged PR #64 replaces event_flag_write: a lookup by flag group picks direct or strided storage, then sets or clears the flag's bit. All 14 authored edge cases match the original, so it is edge-verified, not verified: no game recording reaches it yet, and finding the save state that does is the open question.

No function was implemented, promoted, or newly verified during this documentation audit. The generated baseline remains 21 fully verified and 31 cumulative replaced/edge-verified functions. The AI article now limits its claim to the verified shared-world wrapper; it does not claim that individual enemy or boss decisions have been decoded. Existing original-instruction evidence was not rerun.

Documentation and website changes

Catching up on 11–15 October. @clee's merged PR #68 shows that a US package of the same version reproduces every pinned target hash, so onboarding now says the game version and the dump decide address compatibility, not the title id; other regions and versions remain untested. @ThisIsAkill's merged PR #71 and PR #77 bring the Kernel page in line with the runtime: getpagesize is unresolved, scePthreadEqual and sched_yield are implemented, and scePthreadYield stays unresolved.

The source audit reviewed every current page and generated fragment against merged Paleblood af97b90. Architecture, Runtime, CI, Glossary, and contributor credits now explain the merged tools and their limits. Kernel catches up with the existing thread-call documentation. Event explains the edge-verified flag writer; AI narrows an unsupported broad claim, and Frame Timing labels the saved display result as historical scaffold evidence. Those system-page corrections are under review in Paleblood PR #84. The wiki changes are prepared locally and have not been published.

The site's navigation was redesigned. The header now carries five section tabs (The Hunt, Encyclopedia, Systems, How It Works, For Hunters), and the sidebar lists only the current section's pages at a normal reading size, with the encyclopedia's three parts as headings over their own pages. The sidebar no longer shrinks its text to fit the window, and no section folds away. On small screens the menu button opens a drawer that lists every section. The progress widget became one card with the verified-function count, generated from the same progress data as before. Every page keeps its address. This changes the website only; it does not advance game execution.

The site's runtime numbers now follow the boot record merged in Paleblood PR #92 (7bb7828): 252 of 686 system imports provided (219 by the game's own modules, 33 by the runtime), up from 247, with the boot still stopping at scePthreadAttrGetaffinity in libc.elf at the loaded milestone. The Runtime page describes that run. The count grew; game execution did not advance.
