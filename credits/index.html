Credits

The project stands on other people's work. Names and links are added here as the work they enabled lands; nothing is copied without its license being honored.

Tools

  • SelfUtil-Patched (xSpecialFoodx), based on selfutil (dmiller423): SELF to ELF conversion for the target.
  • orbis-pkg-util: PKG extraction.
  • Ghidra: analysis and the function export that sets the progress denominator.

Runtime contributors

  • Ezequiel Rindello (EzequielRindello): guest-thread handle comparison (PR #62) and the documented sched_yield path (PR #72).
  • Chris Lee (clee): constrained offline network control (PR #59) and explicit unresolved page-size diagnostics (PR #66).

These contributions implement or document runtime contracts. Their synthetic tests do not by themselves establish new game-execution milestones.

Community patch authors

Authors of public community patches whose work documents patch points. One entry per patch is added here when we use it.

  • Kyo (frame-rate patches 30/60/90 FPS++, which located the frame limiter), Lance McDonald (free camera; Uncap FPS++ with Kyo), yogesh1239 (Sprint Fix (High FPS)), auser1337, illusion (skip intro), emoose, and other community members. Which patch each wrote is recorded in the corresponding public patch file; this list is not complete.
